# Сила Скилла: разбор CRM и предложение

Статический сайт-презентация: что нашли в работающей CRM сети детских спортшкол,
что предлагаем и в каком порядке делать.

Четыре страницы: обзор, проблемы, решение, план. Сделан так, чтобы его было удобно
открыть с телефона по ссылке и показать клиенту.

**Живая версия:** https://aa-blinov.github.io/sila-crm-concept/

## Что внутри

| Страница | О чём |
|---|---|
| `/` | Тезис и интерактивная схема входа: как диспетчер выбирает сервер |
| `/problems/` | Шесть находок с ценой каждой: открытый доступ к данным, вход, белые экраны, продления, ссылки на оплату, невидимые клиенты |
| `/solution/` | Три сборки вместо четырёх, геймификация без рейтингов, метрики |
| `/plan/` | Восемь этапов, ворота перед разработкой приложений, арифметика на цифрах CRM |

Все числа взяты из аудита 26 октября 2026. Данные клиентов не публикуются: ни имён,
ни телефонов, ни скриншотов рабочей системы с реальными записями.

## Стек

- SvelteKit 2 и Svelte 5, статическая сборка через `@sveltejs/adapter-static`
- базовый путь сборки приходит из `actions/configure-pages`, поэтому сайт одинаково
  работает и на `username.github.io/repo/`, и на своём домене: при подключении домена
  `base_path` становится пустым, и пересобирать код не нужно
- шрифты лежат в репозитории, внешних CDN нет

## Локально

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в build/
```

Проверить сборку так, как её увидит GitHub Pages:

```bash
npm run build
node tools/serve.cjs      # http://127.0.0.1:4173/sila-crm-concept/
```

## Публикация

Пуш в `main` запускает GitHub Actions и выкладывает `build/` на Pages.

Чтобы подключить свой домен:

1. В настройках репозитория, Pages, поле Custom domain вписать домен.
2. Создать файл `static/CNAME` с доменом в одну строку.
3. В DNS у регистратора добавить запись, которую покажет GitHub.

Пересобирать не нужно: ссылки внутри сайта относительные.

## Структура

```
src/
  app.css                 дизайн-токены и база
  app.html                шапка документа, подключение шрифтов
  routes/
    +layout.svelte        шапка, подвал, нижние вкладки на телефоне
    +page.svelte          обзор и схема входа
    problems/+page.svelte
    solution/+page.svelte
    plan/+page.svelte
static/
  fonts/                  Roboto и Roboto Condensed, загружены локально
  favicon.svg
tools/
  fetch-fonts.cjs         обновить шрифты
  serve.cjs               локальный сервер под префиксом Pages
PRODUCT.md                контекст продукта для этого сайта
DESIGN.md                 дизайн-система: палитра, шрифты, компоненты
```
